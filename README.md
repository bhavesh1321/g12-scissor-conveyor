# G12 Scissor-Expanding Extendable Conveyor

Final-year project: a scissor-expanding, foldable agricultural conveyor.

## Layout

| Folder | Contents |
|---|---|
| `CAD/` | Current full-assembly model: `G12_Extendable_Conveyor_Full_Assembly.step` |
| `SimScale/geometry/` | STEP geometry uploaded to SimScale (cross beam, scissor link) |
| `SimScale/results/` | SimScale results (displacement, von Mises stress) |
| `Documentation/` | Project report, review deck, figures, review 3 submission, faculty messages |
| `references/` | Reference spreadsheet, prototype photos and videos |

Older revisions (rev A-D), generated scripts, renders and demo videos have been removed; they remain in git history.
